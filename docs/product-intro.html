S2S · Self to Self

个人工作台：一个人 + 一台机器，把全部工作流收进一个窗口

以「任务」为中心组织一切——每个任务就是一个独立目录工作区。环境、执行体、Skills、MCP、模型、AI 对话、 编辑器与终端都围绕任务展开，个人即可完成从想法到落地的完整闭环。

任务与看板

  • 任务树 + 任务组，work / code 两类任务，任务即独立目录工作区
  • 看板卡片：未开始 / 进行中 / 待审核 / 已完成，拖拽流转
  • 应用中断后自动续跑进行中卡片，随时可手动停止接管
  • 需求便签：随手记录需求，AI 归类，逐条确认后执行

环境与执行体

  • 本机 / WSL / SSH 三种执行环境
  • 自动探测已装执行体（Claude / zcode / codex / gemini…）
  • 按任务所在环境自动选用执行体，绑定缺失时自动回退
  • CLI 执行体沿用会话记忆（--resume），对话连续不中断

AI 与模型

  • 内置模型与 CLI 执行体，统一对话体验
  • 提供方 → 多模型两级管理，Key 本地加密保存
  • 全局默认模型，任务级可覆盖
  • 多会话、流式输出、思考折叠、停止、排队、图片附件

Skills / MCP

  • 全局 Skills，远程会话自动同步，任务级启用 / 排除
  • 全局 + 任务级 MCP，真实握手测试（initialize + tools/list）
  • 按任务开关技能与工具，控制上下文与权限

工作台与编辑器

  • Monaco 编辑器、文件树、文件 diff、标签页按任务记忆
  • HTML 文件可预览，可在源码与效果间切换
  • 功能图与画板：结构与图形可连同描述一起发给 AI
  • 多标签终端、向右/向下拆分，本机 / WSL / SSH 一致

桌面体验

  • 启动开屏动画，界面秒开可操作
  • 自动检查新版本，一键下载安装
  • VS Code 风格外观：细滚轮、自绘标题栏、原生窗口按钮
  • 数据本地化：业务库 SQLite，对话随任务落盘

P2P · People to People

任务分享：把任务"点对点"交到另一个人手里

每个任务都能生成一个分享链接。另一台装了 zzwork 的机器，只要在自己的某个任务里把这个链接加为 外部执行体，选中它发消息时，问题就会经链接转发到远端的被分享任务，由远端以只读隐藏会话 结合该任务的上下文作答，结果实时回到你的对话里——无需中央服务器，自带公网隧道即可。

分享任务
在任务信息里开启分享，生成带 token 的链接（配合 cloudflared / ngrok 等自带隧道暴露到公网）
→
添加执行体
对方在自己的任务里粘贴链接，经连通性测试后，添加为「远程外部执行体」
→
路由对话
选中该执行体后，本任务 AI 对话即路由到远端，由远端隐藏会话只读作答
→
取回结果
远端答案与本机对话呈现一致；也可只读浏览远端任务目录里的文件
当前状态：任务信息面板里的分享链接、外部执行体与只读问答已可用，正在打磨连接体验、错误提示与文件浏览。 传输不依赖中继服务，成本与数据都留在你自己的机器上。

暴露面被刻意收窄

只读问答
远端以隐藏会话注入任务上下文作答，强制内置模型，仅回文字结论，不驱动代码执行。
只读文件浏览
仅按相对路径读取，realpath 后再校验是否越界；单文件限大小，拒绝二进制。
链接与请求防护
32 字节 token、定长比较、统一 404、仅接受 POST、限流与超时；默认不外泄关键信息与提示词。

T2T · Team to Team

团队协作：从"点对点"走向"面对网"

P2P 让两个人、两个任务能互相调用；T2T 则把它们组织成一个可协作的网络——团队共享任务、环境与知识， 技能与工具在团队内沉淀复用，协作与评审在统一的工作台上流转。以下为方向性规划。

团队工作区
以团队为单位组织任务与目录，成员共享同一工作空间，按项目/职能分层管理。
多人共享任务与看板
任务可在成员间指派与流转，看板成为团队共享的状态视图，评审、待办一目了然。
角色与权限
分享升级为可授权的协作：谁能看、谁能问、谁能改，按角色收敛，而非单一 token。
团队级能力资产
团队共享 Skills、MCP 与模型配置，个人能力沉淀为团队资产，开箱即用。
协作与评审流转
任务从进行中到待审核再到完成，支持他人评审、批注与回退，形成可追溯的协作闭环。
审计与安全
团队内的分享、调用与文件访问可审计；数据边界清晰，敏感信息不外泄。

* T2T 尚处规划阶段，具体形态会随 P2P 的落地经验持续调整。
